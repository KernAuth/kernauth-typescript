# KernAuth TypeScript example

Protocol example for Node.js 24+. This is not the official SDK.

Paste the public app ID, key ID, and public key from the Developers page in place of the placeholders. Run the vector test with:

```
npm install -D vitest
npx vitest run typescript.test.ts
```

A patched program can still skip the check.

Documentation: https://kernauth.apidog.io
